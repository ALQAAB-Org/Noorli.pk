# Security Policy

## Supported Versions

We actively support the following versions with security updates:

| Version | Supported          |
| ------- | ------------------ |
| 5.1.x   | :white_check_mark: |
| 5.0.x   | :x:                |
| 4.0.x   | :x:                |
| < 4.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability, please report it to us as follows:

1. **Do not** create a public GitHub issue.
2. Email the details to [security@noorli.pk](mailto:security@noorli.pk).
3. Provide a detailed description of the vulnerability, including steps to reproduce it.
4. We will acknowledge receipt within 48 hours and provide a more detailed response within 7 days indicating our next steps.

We ask that you give us reasonable time to fix the issue before disclosing it publicly.

Thank you for helping keep Noorli.pk safe!
